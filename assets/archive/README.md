# Media Archive

This is where you drop audio, video, and image files for the project. No coding needed.

- **Pictures** go in `images/`
- **Music or sound clips** go in `audio/`
- **Video clips** go in `video/`

## How to add a file (no software needed)

1. Go to this folder on GitHub.com (ask for the link if you don't have it).
2. Click into the right subfolder (`images`, `audio`, or `video`).
3. Click the **"Add file"** button near the top right, then **"Upload files"**.
4. Drag your file in, or click to browse and select it.
5. Scroll down, write a one-line description of what the file is, and click **"Propose changes"** (or **"Commit changes"**).
6. GitHub will offer to create a pull request for you automatically — say yes. That's it, you're done. Someone will review it before it's added to the actual site.

## File naming

Use short, lowercase, dash-separated names — `sunset-hills.jpg`, `intro-music.mp3`, `dance-clip.mp4`. Avoid spaces and special characters in filenames.

## What happens next

A member of Azams Core will reference your file in the actual website using one of a few standard styles (see the main project README, section on Media Archive) — you don't need to write any code yourself, just get the file uploaded with a clear name and description.
